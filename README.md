A compact chess engine in 4 KB of Python: alpha-beta search with PVS, quiescence, transposition table, killers and an incremental evaluation, playing the house gauntlet to a fixed node budget. Deterministic: the same position always gets the same move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
